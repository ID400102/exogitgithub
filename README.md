# PORTFOLIO HTML/CSS
## DESCRIPTION DU SITE
Ce site présente la landing page du portfolio d'un Developpeur Front-end et Designer UX/UI.
Il a ete codé en HTML et CSS sans aucun framework.
## CHEMIN D'ACCES
Pour accéder à ce Portfolio il suffit de:
Posseder le fichier HTML et le fichier CSS en local dans un même dossier;
Double cliquer sur le fichier HTML nommé "Portfolio.html".
